# Privacy Policy

**Reminder Bully** ("the App") is designed to store your goals locally on your device and only sends information to OpenAI when you explicitly configure your own API key.

## Data Stored

The App stores the following information locally on your device:

* Goals
* Habit history
* Reminder schedules
* Streaks
* Proof submissions
* App settings

This information is not uploaded to any server operated by the developer.

## OpenAI

The App supports Bring Your Own API Key (BYOK).

If you choose to provide an OpenAI API key, the App sends the minimum information required to:

* Generate reminder messages
* Verify submitted proof (if enabled)

This may include:

* Goal title
* Goal description
* Reminder context
* Proof text or images you explicitly submit

Requests are sent directly to OpenAI using your API key.

The developer does not proxy, store, or access these requests.

Please refer to OpenAI's Privacy Policy for information about how OpenAI processes your data.

## Analytics

Reminder Bully does not collect analytics.

## Advertising

Reminder Bully does not display advertisements.

## Tracking

Reminder Bully does not track users across apps or websites.

## Third-Party Services

The App only communicates with OpenAI if you choose to configure an API key.
